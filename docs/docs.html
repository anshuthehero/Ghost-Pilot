Ghost Copilot Documentation

Complete installation, virtual audio configuration, and operational guide for macOS and Windows.

1. Obtain a Free Groq API Key

Ghost Copilot utilizes Groq's high-speed inference engine for real-time speech transcription and streaming responses:

  1. Visit the Groq Cloud Console.
  2. Sign in or create a free account.
  3. Click Create API Key and copy the generated key (starts with gsk_).

💡 Pro Tip: You do not need to edit config files manually. You can paste your Groq API key directly into the Ghost Copilot HUD header once the server launches!

2. Installation & Server Launch

macOS / Linux Setup

# 1. Clone repository
git clone https://github.com/anshuthehero/Ghost-Pilot.git
cd Ghost-Pilot

# 2. Install dependencies (Python 3.10+)
pip install -r requirements.txt

# 3. Launch the assistant backend
python3 app.py

Windows Setup

Windows includes pre-configured 1-click batch scripts: 

# Option A: 1-Click Installer
Double-click install_windows.bat

# Option B: 1-Click Launcher
Double-click start_windows.bat (or run: python app.py)

3. Launching the Stealth Screen-Invisible Client

To ensure the AI responses remain completely invisible when you share your screen on Zoom, Google Meet, Microsoft Teams, or Slack:

Windows Stealth Client

Run the dedicated PyQt6 client which sets the native WDA_EXCLUDEFROMCAPTURE display flag: 

python windows_client.py

macOS Native Bundle

Build the native macOS app bundle with NSWindowSharingNone support: 

bash packaging/macos/build_app.sh

4. Audio Routing & Capture Modes

Mode How It Operates Recommended For
Auto-Listen (VAD) Automatically starts capturing when voice energy is detected, then streams audio to Groq Whisper when speech pauses. Conversational and behavioral interviews where you want completely hands-free operation.
Push-to-Talk (PTT) Hold or toggle keyboard shortcuts (F5 or Spacebar) to capture only the specific question asked. Noisy background environments or complex multi-speaker group discussions.
Browser Microphone Captures audio directly through the web browser or connected mobile device with 1 click. Zero software installation on secondary devices (phone, iPad, Chromebook).

5. Keyboard Shortcuts Reference

Shortcut Action
F5 or Spacebar Push-to-Talk recording toggle.
Esc Instant panic clear: minimizes or clears the streaming HUD immediately.
Cmd / Ctrl + C Clipboard Watcher: automatically solves copied coding or math questions.
