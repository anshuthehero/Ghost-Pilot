Engineered for Performance & Discretion

Every feature is designed to give you real-time technical confidence without distraction.

🛡️ 100% Screen-Share Stealth

Native OS-level window masking via NSWindowSharingNone on macOS and WDA_EXCLUDEFROMCAPTURE on Windows. Completely hidden from Zoom, Meet, Teams, and Slack capture.

⚡ Ultra-Fast Groq Speed

Sub-second speech-to-text using whisper-large-v3 combined with streaming answers from llama-3.3-70b-versatile for near-instant guidance.

🎙️ Dual Audio Modes

Choose between Auto-Listen Voice Activity Detection (VAD) that triggers when the interviewer speaks, or Push-to-Talk (PTT) keyboard shortcuts (F5 / Spacebar).

📋 Clipboard Watcher

Copy any coding challenge, HackerRank problem, or complex behavioral question to receive structured code solutions and optimal time complexity explanations instantly.

⚙️ Customizable System Personas

Tailor the AI assistant to your specific seniority, tech stack, and interview style (e.g. Senior Staff Backend Engineer, System Design Architect, or ML Specialist).

📱 Mobile & Tablet Companion

Open http://<LOCAL_IP>:9471 on your phone or iPad to use it as a dedicated secondary screen, keeping your main monitor completely clean.

🔒 True Window-Manager Level Invisibility

Ghost Copilot does not rely on web hacks or transparent browser tricks. It integrates directly with the native operating system display APIs:

macOS: NSWindowSharingNone

Configures the macOS CoreGraphics window server to omit the Ghost Copilot window from all display stream capture APIs utilized by video conferencing software.

Windows: WDA_EXCLUDEFROMCAPTURE

Applies the Windows Desktop Window Manager (DWM) display affinity flag to exclude the floating PyQt6 HUD from PrintScreen, GDI, and screen recording buffers.
